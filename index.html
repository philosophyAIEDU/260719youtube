체크하고 분석하면 Google 로그인 창이 뜹니다. 로그인한 계정이 이 채널의 소유자일 때만 자막이 반영되며, 다른 사람 채널을 분석할 때는 이 옵션과 무관하게 제목·설명 기반으로 분석됩니다. 자막 API 호출 비용이 커서 대표 영상 소수(기본 5개)만 가져오며, 브라우저당 사용 횟수에 제한이 있습니다.
🔑 자막 분석은 Google OAuth 클라이언트 ID가 한 번 필요합니다

비밀 키가 아니라 공개돼도 되는 식별자라 브라우저에 입력해도 안전합니다. 이 브라우저에만 저장되며, 한 번 입력하면 다음부터는 다시 입력할 필요 없습니다.

  1. Google Cloud Console → 사용자 인증 정보 접속 (YouTube API 키를 만든 것과 같은 프로젝트를 권장)
  2. 아직 안 했다면 OAuth 동의 화면 먼저 설정 — User Type: 외부(External), 테스트 사용자에 본인 구글 계정 이메일 추가
  3. + 사용자 인증 정보 만들기 → OAuth 클라이언트 ID 선택
  4. 애플리케이션 유형: 웹 애플리케이션
  5. "승인된 자바스크립트 원본"에 바로 이 사이트 주소를 정확히 추가:
    -
    ⚠️ file:// 로 열려 있으면 Google이 원본으로 등록해주지 않습니다. python3 -m http.server 등으로 로컬 서버를 띄운 뒤 그 주소(예: http://localhost:8000)를 등록하세요.
  6. "만들기"를 누르면 ...apps.googleusercontent.com 형태의 ID가 발급됩니다. 아래 입력란에 붙여넣고 저장하세요.
