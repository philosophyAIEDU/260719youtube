# Philosophy AI 유튜브 분석 앱 · 브랜드 서사 진단

유튜브 채널을 **조회수·구독자**가 아니라 **“이 사람이 왜 이 채널을 시작했는가”라는 메시지와 서사**의
관점에서 분석하는 개인용 정적 웹 앱입니다. 서버·데이터베이스·회원가입·광고가 전혀 없고,
API 키는 오직 사용자의 브라우저(localStorage)에만 저장됩니다.

## 실행 방법

별도 빌드가 필요 없습니다. `index.html` 을 브라우저에서 열면 됩니다.

1. 우측 상단 **⚙️ 설정** 에서 두 API 키 입력
   - **YouTube Data API 키** — [Google Cloud Console](https://console.cloud.google.com/) 에서 `YouTube Data API v3` 활성화 후 발급
   - **Gemini API 키** — [Google AI Studio](https://aistudio.google.com/app/apikey) 에서 무료 발급
2. 채널 주소/핸들 입력 후 **분석하기**
   - 지원 형식: `@핸들`, `youtube.com/@핸들`, `youtube.com/channel/UC...`, `youtube.com/user/...`, 채널명 검색

> 참고: 일부 브라우저는 `file://` 로 열 때 정적 자산 로딩을 막을 수 있습니다.
> 그럴 경우 이 폴더에서 `python3 -m http.server` 를 실행하고 `http://localhost:8000` 으로 접속하세요.

## 이 앱의 핵심 관점

일반적인 유튜브 분석 도구는 조회수를 성공의 기준으로 삼습니다. 이 앱은 다릅니다.

- **도달(조회수) 과 공명(참여율)을 분리**해서 봅니다. `(좋아요+댓글)/조회수` 가 높은 영상이
  메시지가 사람에게 실제로 가 닿은 영상일 가능성이 큽니다.
- Gemini 에게 보내는 프롬프트는 **자극적 주제/트렌드 편승/썸네일·SEO 팁을 명시적으로 금지**하고,
  창작자의 **‘왜(Why)’ · 메시지 일관성 · 서사 축적 · 차별성** 을 진단하도록 정성껏 설계되었습니다.

## 분석 모델

**Gemini 3.1 Flash Lite (`gemini-3.1-flash-lite`)** 를 사용합니다.
(해당 모델 ID 가 API 에서 아직 노출되지 않아 404 가 날 경우에만 동일 계열 Flash-Lite 로 자동 대체합니다.)

## 결과 화면 구성

프로페셔널 분석 대시보드 형태로, 정량 스코어카드를 중심에 둡니다.

| # | 섹션 | 내용 |
|---|---|---|
| 01 | **브랜드 서사 스코어카드** | 종합 점수(링 게이지·A~D 등급) + 5개 지표(메시지 선명도·일관성·서사 축적력·차별성·오디언스 공명)를 0~100점 바로 시각화. 지표마다 진단과 "이 점수를 올리려면" 제안 포함 |
| 02 | 핵심 메시지 | 이 채널을 왜 시작했는지 추론 + 근거 |
| 03 | 포지셔닝 & 슬로건 | 한 문장 포지셔닝 + 브랜드 슬로건 후보 3개 |
| 04 | **우선순위 액션** | 가장 낮은 점수부터 보완하는 실행안(우선순위·대상 지표·이유·방법) |
| 05 | **90일 브랜딩 로드맵** | 0~30 / 30~60 / 60~90일 단계별 목표와 행동 |
| 06 | 콘텐츠 기둥 | 이 채널이 소유해야 할 콘텐츠 축 3~4개 |
| 07 | 주제 태그 | 핵심 주제 3~5개 |
| 08 | 콘텐츠 리뷰 | 지금까지 콘텐츠를 브랜드 관점에서 패턴별 리뷰 |
| 09 | 공명 분석 | 어떤 유형의 영상이 마음에 가 닿았는지 (조회수 나열 아님) |
| 10 | **채널 소개글 리라이트** | 현재 소개글 → 메시지가 선명한 제안본 (Before/After) |
| 11 | 다음 영상 제안 | 서사를 확장하는 제목 후보 + 서사 기여 설명 |
| 12 | 최근 영상 데이터 | 제목·업로드일·조회수·좋아요·댓글·**참여율**, 모든 열 정렬 가능 |
| 13 | 종합 총평 | 채널의 서사적 정체성과 방향 |

상단에서 **📋 리포트 복사(Markdown)** 와 **🖨️ 인쇄/PDF** 가 가능합니다.

## 파일 구조

```
index.html                진입점 (마크업 + 스크립트 로드)
assets/css/styles.css      다크 네이비 + 골드 포인트, 반응형
assets/js/
  config.js                모델·상수·localStorage 키
  utils.js                 포맷/이스케이프/DOM 헬퍼
  storage.js               API 키 저장 (localStorage 전용)
  youtube.js               YouTube Data API v3 클라이언트
  analysis.js              원시 데이터 → 서사 분석용 신호(도달/공명 분리 등)
  prompts.js               ⭐ 브랜드 서사 프롬프트 (앱의 심장)
  gemini.js                Gemini 3.1 Flash Lite 호출 + JSON 파싱
  ui.js                    결과 렌더링 (정렬 테이블 포함)
  app.js                   전체 흐름 오케스트레이션 + 설정 화면
```

## 보안 / 개인정보

- API 키를 코드에 하드코딩하지 않습니다.
- 키는 브라우저 localStorage 에만 저장되며 외부 서버로 전송하지 않습니다.
- 모든 API 호출은 브라우저에서 Google API 로 직접 이루어집니다(순수 클라이언트 사이드).
